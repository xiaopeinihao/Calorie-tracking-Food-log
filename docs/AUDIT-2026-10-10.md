## 四、复现与验收条件（防复发）

1. 改目标 → 杀进程重启 → 目标仍是用户设的值（A1）。
2. 备份/换机恢复后，`ai_config.xml` 不出现在备份中（A3）。
3. 首次启动 / 种子文件损坏 → 不崩、搜索可用（B1）。
4. 识别进行中连点快门 → 只跑一轮（C2/E2）。
5. 结果页保存编辑 → 明细与餐次同时生效（C3）。
6. 无记录时进趋势页 → 不出现任何「0 千卡 / 0g / 0%」（D1/D2）。
7. 记录页左滑 → 弹确认，取消后记录仍在（E1）。
8. 进相机页 → `CONNECT`；离开 → `DISCONNECT`，活跃客户端为空（F1）。
9. 反复进出页面 8 轮 + 退后台 → PSS 回落，`Activities/ViewRootImpl` 不递增（内存）。
